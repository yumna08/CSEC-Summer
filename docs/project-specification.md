# ASTU CampusGuide AI

## Purpose
Help ASTU students find and understand university
information through a student-friendly web interface.

## Initial users
- ASTU students
- Freshmen
- CSEC-ASTU pilot testers

## Initial information categories
- Academic calendars and announcements
- Library services and resources
- Student services
- Public university procedures

## Core requirements
- Provide helpful, understandable responses.
- Ground factual answers in verified sources.
- Link to supporting information.
- Clearly communicate uncertainty.
- Avoid inventing university policies or deadlines.

## Phase 1 scope
- Establish the repository and architecture.
- Create the Next.js frontend.
- Create the FastAPI backend.
- Connect the frontend to the backend health endpoint.
- Add basic automated tests and documentation.

## Out of scope for Phase 1
- RAG and embeddings
- AI agents and multi-agent workflows
- MCP
- User accounts and authentication
- Student records or private university integrations
